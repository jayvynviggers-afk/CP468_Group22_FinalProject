# CP468 Group 22 — Headline Generation: LSTM Seq2Seq vs. LLM

## Course
CP468-D — Artificial Intelligence

## Task
Headline generation: news article body → headline. We compare a from-scratch
LSTM seq2seq model with attention against an LLM baseline (OpenAI gpt-4.1-nano)
on the same held-out test set.

## Setup
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -c "import nltk"   # rouge/bleu use .split(); no punkt download needed
```

## Reproduce results
All commands run from the repo root. Fixed seed = 468 throughout.

```bash
# 1. Build the dataset (streams XL-HeadTags, filters English, writes splits)
python src/preprocess.py

# 2. Train the LSTM seq2seq + attention model
python src/train.py --epochs 30

# 3. Evaluate the LSTM on the test set (BLEU / ROUGE)
python src/evaluate.py --split test

# 4. Run the LLM baseline (requires an API key)
export OPENAI_API_KEY=sk-...
python src/run_llm_baseline.py --max_examples 1000 --few_shot_k 3

# 5. Score the LLM outputs
python src/evaluate_llm.py
```

> Note: `run_llm_baseline.py` defaults to `--max_examples 5` for quick testing.
> Pass `--max_examples 1000` to reproduce the full 4,000-request run in the report.

## Repository structure

## Dataset
XL-HeadTags (Shohan et al., 2024), English subset, licensed CC-BY-SA-4.0.
https://huggingface.co/datasets/faisaltareque/XL-HeadTags

## Seeds & reproducibility
Global seed 468 (`src/utils.py`). Data split, vocab construction (train-only),
model init, and DataLoader shuffling are all seeded.
